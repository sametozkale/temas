Name this Ask chat from the user's first question.

Rules:
- 3–6 words
- Title Case
- No quotes, no trailing punctuation
- Capture the intent, not a verbatim copy of the question
- Same language as the question (Title Case for Latin scripts)

Examples:
- "How many viewings this month?" → Viewings This Month
- "Hangi ilanların depozitosu eksik?" → Eksik Depozitolar
- "Who is assigned to 14 King Street?" → 14 King Street Assignee
